# Projekt chwytaka pneumatycznego – CAD i analiza mechanizmu

## Opis projektu

Projekt inżynierski wykonany w ramach studiów na kierunku **Automatyka i Robotyka na AGH**.

Celem projektu było zaprojektowanie dwuszczękowego chwytaka pneumatycznego typu **P-(O-P-Op)** przeznaczonego do manipulacji stalowymi elementami cylindrycznymi.

Projekt obejmował modelowanie 3D w **Autodesk Inventor**, analizę kinematyczną i siłową mechanizmu, dobór siłownika pneumatycznego, symulację wytrzymałościową metodą elementów skończonych (MES) oraz przygotowanie dokumentacji technicznej i rysunków złożeniowych.

## Założenia projektowe

- Maksymalna średnica chwytanego przedmiotu: **50 mm**
- Długość przedmiotu: **200 mm**
- Maksymalny ciężar przedmiotu: **37,04 N**
- Nominalne ciśnienie zasilania: **0,6 MPa**
- Napęd: siłownik pneumatyczny dwustronnego działania
- Mechanizm: dwuszczękowy, symetryczny układ dźwigniowy
